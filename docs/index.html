这是什么 about

rscatiacli 是面向 CATIA V5 COM（IDispatch 晚绑定）的 Rust 绑定库 + 工具 CLI， 作为 ltl-manage 应用层 Python CATIA sidecar 的 Rust 替代。API 命名与 pycatia 对齐 （PartDocument、HybridBodies、SPAWorkbench……照搬不擅改）， 但遵循项目的抽取规则：

只封装应用真正用到的成员。 绑定库随应用层的迁移而生长；不做 pycatia 1:1 全镜像。
  • 双层结构：rscatiacli（绑定库：会话/IDispatch/类型化对象模型）与 rscatiacli-tools（工具层：JSON 工具注册表 + CLI）。
  • 进度口径：以"类"为粒度统计。分母 = 14 个规划内模块族的功能类 （剔除 *SettingAtt 设置面板类与 COM 基础设施类； enumeration 的 339 个枚举常量单列、按需引入）。
  • 版本策略：0.0.x 允许破坏性变更；0.1.0 要求覆盖 ≥ 50% 且工具稳定—— 两项均已达标（阶段 1–6 完成后 77.4%），切版时机由维护者决定； 1.0.0 在 pycatia 自身 1.0 前不计划。
  • 真机验证实践：每个阶段配只读探针（examples/phase*_probe.rs， 阶段 4/5 已实跑通过）；探针还修正了多处与 pycatia 标注不同的 COM 实际行为 （如 TemporaryDirectory 返回 Folder 对象、 Release/Version 返回整数、产品身份参数上 ValueAsString 成员缺失）。
  • rscatiacli 侧另有少量 pycatia 没有同名类的扩展封装 （–），不计入分母。
